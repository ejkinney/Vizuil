# Vizuil

Publish completed Vizuil site updates to https://vizuil.kinneyelliot289.chatgpt.site/. Make scene and visualizer changes in `Web`, run `node Prepare-Site.mjs` to refresh `Site/dist`, and deploy to the existing Site identified by `Site/.openai/hosting.json`. A live deployment check is not required before reporting an update as ready. These project instructions cover the hosted site only; standalone Windows app updates are out of scope.
